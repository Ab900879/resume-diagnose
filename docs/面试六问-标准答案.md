# 面试六问 · 标准答案卡

> 来源：2026-11-02 教练问答。左边是问题，右边是开口就能说的版本。
> 背法：不看右边，先把六问自己答一遍，答不出的那问再背。

## 1. 你的用户是谁？

**不合格的答法**：投简历的人、求职者、2027 届本科生。（这是画像，不是人）

**合格的答法**：具体到人。比如：
- 谁：通信工程大三、正在投 AI 产品实习的同学
- 投了多少家：十几家，大部分没回音
- 卡在哪：把“协助社团办活动”写得很满，但说不清自己到底干了什么，也不知道这段算不算“产品经历”

⚠️ 此栏目前是空的——我不是不知道怎么答，是还没认识三个这样的人。**这是整个产品唯一挂着的洞。**

## 2. 用户的问题是什么？

他要的不是“简历更好看”，是**“我这段经历到底算不算数”**。
改措辞解决不了资格焦虑。所以产品第一步不是润色，是先判 A/B/C 类。

## 3. 凭什么用你，不用 ChatGPT？

别的工具给你 10 条润色建议，条条好听。
我的会说：**“这条你没有证据，删掉。”**

原因：每条经历带编号，输出必须挂编号，挂不上就被校验器拦下。
请求（“禁止编造”）和强制（结构化校验）的区别，就是聊天和产品的区别。

## 4. 什么叫做对了？

不是“生成了报告”。可验证的三种结果：
1. 他照着改了，并且投出去了
2. 他主动删了一句原本以为很加分的句子（说明他接受了“证据不足”）
3. 他说“这句我原来没想到”（产品给了他认知增量）

## 5. 成本多少？

- 一次完整诊断 = 两次调用（建事实库 + 诊断）≈ **3300 tokens**
- deepseek-chat ≈ 2 元/百万 tokens → 一次约 **0.007 元**
- 架构是**用户自带 Key**，平台成本 **0**
- 就算日活一千，模型费不到十块。这产品贵的不是钱，是事实库要人工建

## 6. 你不做什么？

- 不生成整份简历
- 不打分
- 不美化
- 不编造（结构强制，不是提示词请求）
- **不替没经历的人包装**——资格不够时直说 C 类，建议先攒经历再投
